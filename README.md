## 🌐 Overview
This repository contains the source code for the **Movonix Solutions** website. Designed with a modern "Cyber-Tech" aesthetic and our signature "Trust Blue" theme, this platform showcases our digital agency services, portfolio, and provides a seamless way for clients to get in touch globally.

## ✨ Features
- **Premium UI/UX:** Glassmorphism effects, floating contact cards, and smooth modern animations.
- **Brand Aesthetic:** Built with a professional "Trust Blue" color palette.
- **Fully Responsive:** Mobile-optimized spacing ensuring a flawless display across all devices.
- **Contact Integration:** Fully functional form submission with professional success popups.
- **High Performance:** Clean, fast, and optimized code built with React, Vite, and TypeScript.
